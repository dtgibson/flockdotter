# Flock Dotter

Flock Dotter helps you count birds or other objects in a photo. Tap each one in turn, or click on Mac. Each mark shows what you’ve counted and updates the total.

1. Open a photo from Photos or Files. Zoom in to see smaller items.
2. In **Count**, tap each item once. Use **Undo** for a stray tap, or switch to **Edit** to move or remove a mark.
3. Choose **Export** to save a marked-up PNG. To keep counting later, save **Count JSON** and **Original Photo** together. Reopen the JSON with that exact photo.

The app works offline and remembers one current photo and count between launches. You can change the color and style of the marks, renumber them, and show lines between consecutive marks. Very large counts can take several seconds to redraw.
